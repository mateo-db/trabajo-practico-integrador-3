> ## Proyecto API REST desarrollado con Node.js, Express y MongoDB, orientado a la gestión de usuarios, eventos y categorías. Permite administrar eventos, establecer relaciones entre entidades y gestionar el acceso de usuarios mediante autenticación y autorización.
>
> ## Tecnologías Utilizadas:
>
> - ### `Node.js`
> - ### `Express`
> - ### `MongoDB`
> - ### `Mongoose (ODM)`
> - ### `Express Validator`
> - ### `JSON Web Token`
> - ### `Bcrypt.js`
> - ### `ES Modules`
>
> ## Como correr el proyecto
>
> - ### Clonar el repositorio
> - ### Instalar dependencias (`npm i`)
> - ### Configurar variables de entorno (ver `.env.example`)
> - ### Ejecutar `npm run dev`
